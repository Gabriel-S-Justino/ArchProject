# Mission Architect

RPG de cartas para o NASA Space Apps Challenge 2026: projete, gerencie e simule uma missão espacial completa.

```bash
npm install
npm run dev     # http://localhost:3000
npm test        # testes do engine (Vitest)
npm run build
```

Documentação do projeto: `Contexto.md` → `Arquitetura.md` → `Desenvolvimento_guiado.md`. Estado atual em `PROJECT-STATE.md`.
